## Findings

1. **Worktree desired-state safety remains broken.** `pkgs/crates/agentboard-action-worktree/src/runtime.ts` accepts the repository main worktree as a managed root, cannot create a missing branch when an existing managed worktree must switch, and lets `cachedSuccessIsValid()` accept arbitrary same-repository paths. This violates `.memory/docs/adr/pkgs/crates/agentboard-action-worktree/0012-ensure-worktree-desired-state.md`. File: `pkgs/crates/agentboard-action-worktree/src/runtime.ts`.
2. **Cancellation can persist a successful Action attempt.** `apps/cli/src/services/runtime.ts` appends the returned Action result before checking cancellation. A custom Action can return `success`, then cancellation can occur, and the Store records `success` instead of `cancelled`. This violates `.memory/docs/adr/0012-use-cooperative-cancellation-through-runtime-contexts.md`. File: `apps/cli/src/services/runtime.ts`.
3. **Cancelled Source collections can leave an authoritative snapshot.** `appendSourceSnapshot()` writes the snapshot boundary after a cancellation check, and cancellation can occur between that boundary write and collection status handling. This violates `.memory/docs/adr/0012-use-cooperative-cancellation-through-runtime-contexts.md`. Files: `apps/cli/src/services/runtime.ts`, `apps/cli/src/services/store.ts`.
4. **Process-group cancellation is incomplete.** All new Bun runtimes fall back from negative-PID process-group termination to `child.kill()`, which kills only the direct shell. Descendant processes can remain alive. This violates `.memory/docs/adr/0012-use-cooperative-cancellation-through-runtime-contexts.md`. Files: `pkgs/crates/agentboard-action-run-cmd/src/runtime.ts`, `pkgs/crates/agentboard-action-worktree/src/runtime.ts`, `pkgs/crates/agentboard-source-github/src/runtime.ts`, `pkgs/crates/agentboard-source-jira/src/runtime.ts`, `pkgs/crates/agentboard-source-qmd/src/runtime.ts`.
5. **Already-aborted health-check waits can hang for the full interval.** `wait()` attaches the abort listener without checking `signal.aborted` first. File: `pkgs/crates/agentboard-action-run-cmd/src/runtime.ts`.
6. **The output-cap regression test is timing-dependent.** `pkgs/crates/agentboard-action-run-cmd/src/runtime.test.ts` uses a 3 ms health-check timeout and requires probe output. Repeated execution failed because the probe did not start before the deadline. File: `pkgs/crates/agentboard-action-run-cmd/src/runtime.test.ts`.
