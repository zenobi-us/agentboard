## Spec

The implementation matches the handoff requirements:

- Exports one GitHub Source Plugin Descriptor.
- Uses the shared `FieldMapSchema`.
- Collects issue-mode records and preserves raw GitHub payloads.
- Injects `is:issue` when the query does not include it.
- Rejects pull requests and duplicate normalized item ids.
- Applies label status mappings before issue-state mappings.
- Uses `owner/repo#number` item ids by default.
- Runs the credential helper and validates the token through GitHub during `doctor` health checks.
