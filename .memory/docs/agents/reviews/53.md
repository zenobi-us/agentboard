## Findings

The QMD Source exports one Plugin Descriptor with the shared TypeBox field map. It invokes `qmd query` with the configured query, collections, limit, JSON output, and full document bodies.

The runtime normalizes QMD documents into Items. It keeps the QMD result, frontmatter, and document body in `raw`. It keeps the QMD document reference in `item.id` and the mapped frontmatter identifier in `item.reference_id`.

The runtime rejects duplicate document references, malformed result values, invalid JSON shapes, missing commands, non-zero QMD exits, and missing frontmatter fields. It reads stdout and stderr while QMD runs. It stops the detached process group on cancellation and checks cancellation immediately after process creation.

Tests cover the descriptor, normalization, field mapping, raw payloads, duplicate references, health checks, Workspace runtime execution, and the actual Bun CLI `run` command.

The source test is not a Moon task because `agentboard-source-qmd/moon.yml` is Rust-only and the ticket forbids Rust task configuration changes. The required focused Bun test command runs it directly.
