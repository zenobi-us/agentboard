# Why AgentBoard

Task trackers are good at tracking. Agents need repeatable local work queues.

AgentBoard copies task-like items from Jira, Linear, GitHub, and markdown into a local store, then runs configured actions such as syncing state, creating worktrees, and launching commands.

AgentBoard is deliberately not a tracker replacement. Keep truth upstream. Use AgentBoard as the local automation bridge.
